# v0.1 release readiness

## Release decision

Ship the six Skills as `experimental 0.1.0`, not `stable`. They are ready for GitHub review, installation from a fixed commit and controlled user trials.

## Included

- Two XOPC Original Skills with tested deterministic helpers.
- Four MIT XOPC Adapted Skills discovered or prioritized through VoltAgent and traced to original repositories.
- Eight registered scenarios: six implemented, one future XOPC Tunnel scenario and one media research scenario.
- One remaining upstream-only opportunity for Next.js production review.

## Automated evidence

Run before tagging:

```bash
npm run validate
npm run test:scripts
npm run check:voltagent
```

The release is blocked if any Skill lacks a registry record, 10 positive and 10 near-miss triggers, five task fixtures, a valid local reference, source attribution, or declared stable blockers.

## Manual release checklist

- Review all `SOURCE.json` records and `THIRD_PARTY_NOTICES.md`.
- Confirm the target GitHub organization and repository visibility.
- Enable branch protection with required `quality` workflow.
- Add repository topics: `agent-skills`, `codex`, `claude-code`, `xopc`, `mcp`.
- Create tag `v0.1.0` only after CI passes on GitHub.
- Start controlled trials from a fixed commit; do not advertise these Skills as stable.

## Stable promotion

Each `registry/skills/*.json` lists its own blockers. Promotion additionally requires trigger precision/recall targets, task success versus no-Skill baseline, compatibility evidence, assigned domain/security reviewers and at least one feedback-driven revision.
