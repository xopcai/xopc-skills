# v0.2 release readiness

## Scope

Six experimental Skills add decision research, meeting execution, content campaigns, prospect research, document requirement review and weekly planning. Existing API integration and software delivery Skills remain unchanged.

## Required checks

- [ ] `npm run validate`
- [ ] `npm run test:scripts`
- [ ] `npm run check:voltagent`
- [ ] `quick_validate.py` passes for every Skill
- [ ] Every distributed Skill belongs to exactly one of eight scenario groups
- [ ] No scenario group exceeds 20 Skills
- [ ] All adapted sources have a pinned commit, license and copyright notice
- [ ] Git diff contains no unrelated files or secret/native artifacts
- [ ] GitHub Actions passes on `main`

## Experimental limitations

The 120 trigger fixtures and 30 task fixtures are authored evaluation assets, not measured model baselines. Stable promotion remains blocked until realistic tasks compare no-Skill and with-Skill outcomes, including permission failures and misleading source inputs.

## Tagging

Create `v0.2.0` only after the pushed commit passes GitHub Actions and release notes are approved.
