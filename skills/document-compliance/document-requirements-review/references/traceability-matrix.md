# Traceability matrix

Use one row per atomic requirement.

| ID | Requirement | Source location | Modality | Expected evidence | Document evidence | Evidence location | Status | Gap / conflict | Remediation | Owner |
|---|---|---|---|---|---|---|---|---|---|---|

## Status rules

- `met`: direct, current evidence demonstrates the full requirement.
- `partial`: some clauses or required evidence are absent.
- `missing`: no relevant evidence found.
- `conflict`: document evidence contradicts the requirement or another authoritative section.
- `ambiguous`: requirement or evidence admits materially different interpretations.
- `not-applicable-with-rationale`: user/authority-supported exclusion, never convenience.

Headings, future intentions, generic assurances, and self-assertions are not evidence unless the requirement explicitly asks for them.
