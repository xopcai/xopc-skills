# Data protection

## User outcome

Create a purpose-specific redacted copy and evidence that sensitive values are no longer recoverable from the intended output.

## Selected Skills

- `privacy-redaction` owns sensitive-field inventory, transformation choice, copy-only processing, visual and machine-readable verification, and protected mapping handling.

## Boundary

Software code security remains in `software-security`. This scenario does not make legal compliance certifications or alter originals by default.
