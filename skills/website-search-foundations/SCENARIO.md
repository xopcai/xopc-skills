# 建设可发现的网站基础

## User outcome

形成可实施、可验证的程序化页面、结构化数据和信息架构方案。

## Selected Skills

- `programmatic-seo` — 规划程序化 SEO 页面。
- `schema` — 实施结构化数据。
- `site-architecture` — 设计网站信息架构。

## Boundary and overlap

每个 Skill 只负责其名称所示的主要任务；相邻 Skill 通过已确认的 brief、证据表或测量计划衔接。研究、创作、执行和外部账户变更不得被隐式合并。
