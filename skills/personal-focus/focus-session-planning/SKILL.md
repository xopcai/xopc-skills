# Focus Session Planning

Confirm available time, energy, environment, hard deadline, candidate tasks, and what would make the session worthwhile. Select one primary outcome by urgency, value, readiness, and fit with current capacity.

Define a visible finish condition and the smallest first physical action. Split work only until each unit can be started without further planning. Reserve setup and shutdown time; choose a session length appropriate to the work rather than forcing a fixed timer.

Prepare required files and tools, silence only nonessential interruptions, and record a safe capture place for incoming thoughts. Identify one likely blocker and a fallback action. Do not hide notifications that protect safety or caregiving responsibilities.

At the end, record completed evidence, where to resume, blockers, and one adjustment for the next session. Treat interruption data as environment feedback, not a character judgment. Never diagnose ADHD, anxiety, or another condition from productivity behavior.
