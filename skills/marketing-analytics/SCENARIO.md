# 建立营销测量与归因

## User outcome

把业务问题和事件数据转化为可审计的测量、分析与归因方案。

## Selected Skills

- `analytics` — 设计营销分析方案。
- `attribution` — 设计营销归因方案。

## Boundary and overlap

每个 Skill 只负责其名称所示的主要任务；相邻 Skill 通过已确认的 brief、证据表或测量计划衔接。研究、创作、执行和外部账户变更不得被隐式合并。
