# 制作营销图片与视频

## User outcome

把营销 brief 转化为有平台规格、品牌约束和验收标准的媒体资产。

## Selected Skills

- `image` — 制作营销图片。
- `video` — 制作营销视频。

## Boundary and overlap

每个 Skill 只负责其名称所示的主要任务；相邻 Skill 通过已确认的 brief、证据表或测量计划衔接。研究、创作、执行和外部账户变更不得被隐式合并。

## Source decision
