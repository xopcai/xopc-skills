# Group Scheduling

Normalize the date window, duration, timezone, required and optional attendees, working hours, minimum notice, buffers, recurrence, location, and hard constraints. Use free/busy data when available and clearly label partial visibility.

Rank a short list rather than enumerating every opening. Required-attendee fit outranks optional fit. Avoid unreasonable local times, lunch when relevant, back-to-back compression, calendar fragmentation, travel conflicts, and consuming the only large focus block unless meeting priority justifies it. Treat tentative or working-elsewhere status as softer than busy or out-of-office, subject to user preferences. Include room or hybrid logistics when available.

Return two to four options with all relevant timezones, why each works, conflicts or inconvenience, confidence, and a recommendation. If no clean option exists, explain the tradeoff and which constraint would need relaxing. Creating invitations, booking rooms, or changing existing events requires confirmation of the winning slot, attendees, title, duration, timezone, and recurrence.
