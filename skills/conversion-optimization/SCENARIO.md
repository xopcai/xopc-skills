# 优化关键转化界面

## User outcome

基于用户意图和证据改进页面、注册、引导、付费墙与弹窗。

## Selected Skills

- `cro` — 优化营销页面转化。
- `onboarding` — 优化产品引导体验。
- `paywalls` — 优化应用内付费墙。
- `popups` — 设计转化弹窗。
- `signup` — 优化注册流程。

## Boundary and overlap

每个 Skill 只负责其名称所示的主要任务；相邻 Skill 通过已确认的 brief、证据表或测量计划衔接。研究、创作、执行和外部账户变更不得被隐式合并。
