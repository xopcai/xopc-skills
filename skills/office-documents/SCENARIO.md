# Office documents

## User outcome

Create, edit, or review professional Word and PDF deliverables while preserving source content, structure, and visual quality.

## Selected Skills

- `document-authoring` owns editable Word-compatible documents.
- `pdf-workbench` owns fixed-layout PDF review, creation, reformatting, and forms.

## Boundary

Document compliance review remains separate. A request for prose without a file deliverable does not require these Skills.
