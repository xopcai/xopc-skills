# Brand Style Application

Confirm the target artifact, authoritative brand sources, allowed logo variants, color and typography rules, imagery style, audience, medium, and accessibility or regulatory constraints. Distinguish mandatory rules from examples and preferences. If no approved guide exists, offer a clearly labeled draft direction instead of presenting invented choices as official brand policy.

Translate the guide into a compact token set: semantic colors, typography roles, spacing and shape rules, logo clear space, imagery treatment, and medium-specific fallbacks. Preserve existing content and information hierarchy unless the user separately asks to redesign them. Never copy another organization's distinctive identity.

Apply tokens consistently through reusable styles rather than one-off formatting. Respect the artifact's native template and platform limitations. Use licensed, embeddable fonts or documented fallbacks; keep logos undistorted and ensure sufficient contrast, legibility, focus visibility, and non-color cues.

Render or preview every materially different page, slide, view, or breakpoint. Audit token coverage, contrast, overflow, logo use, font fallback, imagery rights, and deviations from the guide. Return the source guide and version, token summary, changed artifact, exceptions and reasons, accessibility checks, and unresolved approvals.

Brand application does not authorize trademark decisions, external publishing, or substantive claims. Route document, presentation, web, or campaign creation to the corresponding artifact Skill, then use this Skill for brand conformance.
