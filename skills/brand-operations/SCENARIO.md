# Brand operations

## User outcome

Apply an approved brand system consistently and accessibly across an existing artifact while preserving its content and recording exceptions.

## Selected Skills

- `brand-style-application` owns guide extraction, semantic tokens, application, and conformance audit.

## Boundary

This group does not invent company identity or create substantive artifact content. Artifact-specific Skills own documents, slides, web interfaces, and campaigns; brand application supplies and verifies their visual constraints.
