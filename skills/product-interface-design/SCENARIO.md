# Product interface design

## User outcome

Turn a real product brief into a distinctive, responsive, accessible web interface whose visual system and interaction states are verified in the rendered result.

## Selected Skill

- `frontend-design` — adapted from [Anthropic's frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design), the clear adoption leader in this category. XOPC retains its subject-specific visual direction and critique loop while tightening scope, truthfulness, accessibility, and rendering evidence.

## Boundary and overlap

This scenario owns substantial visual design and implementation. Tiny CSS fixes remain ordinary coding tasks; product research, campaign strategy, image generation, and generic frontend architecture remain separate.

## Evaluated alternatives

- MiniMax `frontend-dev` covers a much broader full-stack and media workflow, creating ambiguous triggers and unnecessary provider coupling.
- Anthropic was selected over lookalike frontend-design Skills because it is the original first-party source, explicitly Apache-2.0 licensed, narrowly scoped, and most widely adopted.
