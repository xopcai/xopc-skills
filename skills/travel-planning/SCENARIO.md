# Travel planning

## User outcome

Build a feasible, current, budget-aware itinerary with explicit booking assumptions, geographic sequencing, accessibility needs, and fallback options.

## Selected Skills

- `travel-itinerary-planning` owns trip requirements, live-fact verification, route feasibility, budget ranges, reservations, daily pacing, and contingency planning.

## Boundary

Ordinary calendar scheduling remains in `calendar-productivity`. This Skill plans but does not book, purchase, submit visa applications, or guarantee entry, weather, price, or availability.
