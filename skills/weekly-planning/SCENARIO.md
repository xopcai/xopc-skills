# Weekly planning

## User outcome

Close open loops, protect constraints, calculate realistic capacity, choose priorities, and produce a feasible next-week plan.

## Selected Skill

- `weekly-planning-review` — adapted from [Alireza Rezvani's Claude Skills](https://github.com/alirezarezvani/claude-skills), a maintained MIT-licensed collection. XOPC added explicit capacity arithmetic, overload trade-offs, scoped data access, and approval before writes.

## Boundary and overlap

The Skill owns weekly review and planning, not daily task execution, meeting action extraction, team retrospectives, calendar automation, or project portfolio management.

## Evaluated alternatives

- Broad personal-productivity Skills were not added because they duplicate the weekly-planning trigger with less precise output contracts.
- Dedicated daily planning or team planning should become separate Skills only after proving distinct users, inputs, and acceptance criteria.
