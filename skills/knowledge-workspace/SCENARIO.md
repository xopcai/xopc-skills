# 企业知识检索与综合

## User outcome

Turn scattered workspace evidence into a current, cited answer without changing source systems.

## Selected Skills

- `workspace-knowledge-synthesis` owns 对跨文档、邮件、聊天和任务结果去重、处理冲突并形成带来源和置信度的答案.

## Boundary

Each Skill owns one primary result artifact. Source-system writes, messages, assignments, and permission changes require explicit authorization and stay outside read-only synthesis.
