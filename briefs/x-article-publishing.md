# Scenario Brief: 把 Markdown 长文保存到 X Articles

## User job

把本地 Markdown 和图片转换为可核验的 X Articles 草稿，并在明确授权后发布。

## Inputs

- 指定的源文件、URL、账户或运行记录
- 目标交付物、受众和验收标准
- 权限、隐私、法律、平台和工具约束

## Acceptance criteria

- 来源版本和处理范围可追溯。
- 输出语法或审查记录可验证，失败与不确定性可见。
- 外部变更、敏感数据与高风险判断遵守明确边界。

## Non-goals

不重复现有通用能力，不承诺完美检测、法律结论、平台可用性或业务效果。
