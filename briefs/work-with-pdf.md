# Scenario Brief: work-with-pdf

## Outcome

Read, create, reformat, combine, split, rotate, annotate, or fill a PDF while preserving fixed-layout meaning and verifying changed pages.

## Boundaries

- Signatures and attestations are never invented.
- OCR uncertainty and unsupported interactive elements are disclosed.
- Editable Word deliverables use document authoring.

## Evaluation

Fixtures cover scanned text, forms, reordered pages, bookmarks, annotations, broken glyphs, clipping, and password protection.
