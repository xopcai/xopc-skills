# Scenario Brief: author-professional-document

## Outcome

Create or edit an editable professional document whose content, structure, styles, accessibility, and rendered pages are verified.

## Boundaries

- Existing templates and source files are authoritative and preserved by default.
- Plain prose and document compliance review remain separate.
- Structural parsing alone is not sufficient when visual layout matters.

## Evaluation

Fixtures cover new reports, template filling, tracked edits, tables, numbering, headers, inaccessible images, and page overflow.
