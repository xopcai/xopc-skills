# Scenario Brief: create-presentation-deck

## Outcome

Create or edit an editable presentation whose narrative, evidence, template fidelity, slide objects, and rendered appearance are verified.

## Boundaries

- A plain outline or single graphic is not a presentation-deck task.
- Existing masters, notes, hidden slides, and links are preserved unless changed.
- Every slide is rendered and inspected before delivery.

## Evaluation

Fixtures cover executive, training, sales, and data decks; template edits; chart labels; font substitution; overflow; and weak narrative structure.
